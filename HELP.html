🚀 Hilfe: So startest du die Webseite

0. WICHTIG: Node.js installieren

Der Fehler "npm wurde nicht gefunden" bedeutet, dass die Basis-Software (Node.js) auf deinem Computer fehlt.

  1. Gehe auf nodejs.org.
  2. Lade die Version "LTS" (Recommended For Most Users) herunter und installiere sie.
  3. Wichtig: Starte das Terminal danach einmal komplett neu!

1. Das Terminal öffnen

Ein "Terminal" ist ein Programm, in dem man Befehle eintippt. So findest du es:

Windows Drücke die Windows-Taste und tippe PowerShell oder cmd ein. Drücke Enter.

Mac Drücke Cmd + Leertaste und tippe Terminal ein. Drücke Enter.

So findest du den Pfad ganz einfach:
  1. Tippe im Terminal cd (mit einem Leerzeichen am Ende).
  2. Nimm den Ordner "garage-rolli-redesign" von deinem Schreibtisch (oder wo du ihn gespeichert hast) mit der Maus.
  3. Ziehe ihn einfach direkt in das Terminal-Fenster hinein.
  4. Das Terminal schreibt den Pfad automatisch für dich! Drücke dann nur noch Enter.

2. Die Webseite starten

Sobald das Terminal im richtigen Ordner ist, tippe diese zwei Befehle nacheinander ein:

npm install (Nur beim ersten Mal nötig)
npm run dev

3. Im Browser anschauen

Im Terminal erscheint nun ein Link wie:

➜ Local: http://localhost:5173/

Halte Strg (oder Cmd) gedrückt und klicke auf diesen Link, oder kopiere ihn in deinen Browser.

🛠 Den "dist" Ordner erstellen

Falls du die Dateien für einen Webserver brauchst (den dist Ordner), tippe:

npm run build

Der Ordner erscheint danach sofort links in deiner Dateiliste.

⚠️ Fehler: "Ausführung von Skripts deaktiviert" (Windows)

Falls Windows das Ausführen von npm verbietet, musst du es einmalig erlauben:

  1. Öffne das Startmenü, tippe PowerShell ein.
  2. Rechtsklick darauf -> Als Administrator ausführen.
  3. Kopiere diesen Befehl hinein und drücke Enter:
    4. Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  4. Bestätige mit "Y" (oder "J").
  5. Jetzt kannst du dein normales Terminal wieder nutzen!
