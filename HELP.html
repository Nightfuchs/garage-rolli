🚀 Hilfe: So startest du die Webseite

1. Das Terminal öffnen

Ein "Terminal" ist ein Programm, in dem man Befehle eintippt. So findest du es:

Windows Drücke die Windows-Taste und tippe PowerShell oder cmd ein. Drücke Enter.

Mac Drücke Cmd + Leertaste und tippe Terminal ein. Drücke Enter.

Wichtig: Navigiere im Terminal zu diesem Ordner (mit dem Befehl cd gefolgt vom Pfad).

2. Die Webseite starten

Sobald das Terminal im richtigen Ordner ist, tippe diese zwei Befehle nacheinander ein:

npm install (Nur beim ersten Mal nötig)
npm run dev

3. Im Browser anschauen

Im Terminal erscheint nun ein Link wie:

➜ Local: http://localhost:5173/

Halte Strg (oder Cmd) gedrückt und klicke auf diesen Link, oder kopiere ihn in deinen Browser.

🛠 Den "dist" Ordner erstellen

Falls du die Dateien für einen Webserver brauchst (den dist Ordner), tippe:

npm run build

Der Ordner erscheint danach sofort links in deiner Dateiliste.
